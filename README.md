# HỆ THỐNG QUẢN LÝ SINH VIÊN VÀ KHÓA HỌC
**Student & Course Management System (PRO192 Final Assignment)**

## 1. Giới Thiệu
Ứng dụng quản lý sinh viên là bài tập lớn cho môn Lập trình Hướng Đối Tượng với Java (PRO192). Ứng dụng này cung cấp môi trường CLI quản lý Sinh viên, Khóa học, lớp Đăng ký (kèm điểm số), được xây dựng trên Collection Framework và xử lý đọc/ghi Text File.

## 2. Các Tính Năng Chính
1. **Quản lý Sinh viên:** Thêm, Sửa, Xóa, Tìm kiếm, Sắp xếp (Hỗ trợ Data Regex/Validation).
2. **Quản lý Khóa học:** Quản lý số tín chỉ, thông tin chung.
3. **Quản lý Đăng ký:** Ghi nhận sinh viên vào khóa học và lưu trữ kết quả điểm số hệ 10.
4. **Auto-Generate 100+ Data Logs:** Tạo lập 100 dòng test data làm SeedData ngay lần đầu tiên mở ứng dụng.
5. **Persistence:** Ghi file tự động (`students.txt`, `courses.txt`, `enrollments.txt`).

## 3. Cấu Trúc Project

```
StudentManagement_NhomXX/
├── .gitignore               # Loại bỏ file rác NetBeans
├── README.md                # Giới thiệu dự án
├── AI_LOG.md                # Tên, Prompt, Code Generated By AI
├── src/                     # Source Code
│   ├── Main.java            # Main Control & Menu View
│   ├── models/              # Lớp đối tượng: Person, Student, Course, Enrollment 
│   ├── managers/            # Xử lý Logic: IManager, StudentMgr,...
│   └── utils/               # Tiện ích: Validation, GenData
├── data/                    # Text Files Output
└── docs/                    # Sơ đồ và Proposal
```

## 4. Hướng Dẫn Sử Dụng
**Chạy trên IDE (Khuyên dùng NetBeans):**
1. Mở Project với NetBeans IDEA.
2. Build Project để lấy IDE gen tự động src ra `/dist/app.jar`.
3. Nhấn `Run > Run Project`.

**Biên dịch trực tiếp từ Console:**
```bash
cd src
javac -encoding UTF-8 utils/*.java models/*.java managers/*.java Main.java
java Main
```
